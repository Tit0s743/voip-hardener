# voip-hardener
 Что делает скрипт
VoIP Hardener — это скрипт автоматического харденинга VoIP-серверов на базе Asterisk (совместим с GoIP / DBL). Запускается одной командой и за 30–60 секунд приводит сервер в состояние базовой, но надёжной защиты от типовых VoIP-атак.
🔧 Основные возможности
 Умное сканирование конфигурации Asterisk — автоматически определяет SIP-порты из pjsip.conf (bind=) и sip.conf (bindport=), а также RTP-диапазон из rtp.conf
 Настройка UFW Firewall — открывает только необходимые порты (SSH, SIP, SIPS, RTP, IAX2, HTTP/HTTPS), всё остальное блокируется по умолчанию
 Fail2ban с тюнингом под VoIP — защита от брутфорса SIP-аккаунтов (бан на 7 дней) и SSH (бан на 24 часа), плюс jail recidive для рецидивистов (бан на месяц)
 Харденинг ядра (sysctl) — защита от SYN flood, IP spoofing, ICMP-redirect и source routing
 Автоматическая подготовка окружения — ожидание apt-lock, установка обновлений, доустановка недостающих пакетов, проверка сети и DNS
 Проверка Asterisk — контролирует наличие логов security-канала, создаёт директорию /var/log/asterisk при необходимости
 Интеграция с UFW — Fail2ban использует нативный banaction = ufw, что исключает конфликты с iptables
 От чего защищает
Брутфорс SIP-аккаунтов
Fail2ban jail sshd (3 попытки → бан на сутки)
Рецидивисты
SIP-сканеры и toll fraud
UFW + Fail2ban + запрет гостевых вызовов
SYN flood, spoofing
Sysctl-параметры ядра
Сканеры портов
UFW default deny + отключение ICMP
⚙️ Системные требования
ОС: Ubuntu / Debian (используется apt)
Права: root или sudo
Asterisk: любая версия (опционально, но рекомендуется для работы SIP-jail)
